# ADR 0001: Логіка живе окремо від інтерфейсу

Дата: 2026-11-18
Статус: прийнято

## Контекст

Перерахунок рецептів потрібен у вебінтерфейсі зараз, а пізніше на сервері й у розрахунку БЖВ.

## Рішення

Уся предметна логіка лежить у `src/core` як чисті функції TypeScript без React, браузерних API та бази даних.

## Наслідки

- Логіку можна швидко тестувати без браузера.
- Інтерфейс або базу даних можна замінити без переписування розрахунків.
- Потрібна дисципліна: у `src/core` не можна імпортувати код інтерфейсу.
