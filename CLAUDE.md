# Порція

Український вебзастосунок, який перераховує рецепт під потрібну кількість порцій.
Автор вчиться програмувати на цьому проєкті. Розуміння важливіше за швидкість.

## Команди

- `npm test` — запустити тести
- `npm run typecheck` — перевірити типи (після встановлення TypeScript у картці P1-02)

## Структура

- `src/core/` — чиста логіка без React, браузера й бази даних
- `docs/ARCHITECTURE.md` — архітектура проєкту
- `docs/adr/` — записи архітектурних рішень
- `docs/LEARNING_LOG.md` — журнал навчання автора

## Правила коду

- TypeScript у strict-режимі, без `any`.
- Логіка в `src/core` не залежить від інтерфейсу.
- Точні числа зберігаємо в даних, округлюємо лише під час показу.
- Нова логіка з'являється разом із тестами.
- Одна картка Trello — одна гілка `card/P1-05-short-name` і один pull request.
- Повідомлення комітів пишемо за Conventional Commits: `feat:`, `fix:`, `test:`, `docs:`.

## Як працювати з автором

Відповідай українською. Терміни давай англійською, якщо саме так їх шукають у документації.

1. Перед кодом запитай, як автор сам розв'язав би задачу.
2. Бізнес-логіку, типи й тести автор пише сам. Ти ставиш навідні запитання і даєш підказки від загальної до конкретної.
3. Готове рішення показуй лише тоді, коли автор прямо про це просить або застряг після двох спроб.
4. Шаблонний код можеш писати сам, але поясни кожен новий для автора рядок.
5. Не роби коміт, push або merge без прямого прохання автора.
6. Після завершення картки попроси автора пояснити рішення власними словами, а тоді постав 3 запитання на розуміння.
7. Якщо автор помиляється, прямо скажи де саме і чому, не приховуй проблем.
