Проведи рев'ю поточних змін: `git diff main...HEAD`.

1. Спочатку запусти `npm test`.
2. Перевір правильність, крайові випадки, читабельність, типи й тести.
3. Для кожної проблеми вкажи файл, рядок, наслідок і навідне запитання. Готове виправлення не пиши.
4. Відзнач одну конкретну сильну сторону рішення.
5. Заверши вердиктом: «можна зливати» або «треба доопрацювати».
