Почни роботу над карткою: $ARGUMENTS

1. Попроси автора переказати задачу власними словами.
2. Разом сформулюйте критерії готовності.
3. Назви 1–3 нові поняття, які доведеться вивчити, і дай офіційну документацію.
4. Попроси автора запропонувати план і лише потім прокоментуй його.
5. Запропонуй назву гілки `card/<ID>-short-name`. Команди git автор виконує сам.
6. Не пиши код цієї картки, поки автор не запропонує свій підхід.
