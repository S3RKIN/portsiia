Перевір розуміння теми: $ARGUMENTS

1. Попроси автора пояснити рішення так, ніби він розповідає його на співбесіді.
2. Не виправляй одразу. Знайди прогалини й постав по одному уточнювальному запитанню.
3. Дай 3 запитання: «чому так», «що зламається, якщо…», «як зробити інакше».
4. Оціни кожну відповідь як «розумію», «частково» або «повторити».
5. Запропонуй короткий запис для `docs/LEARNING_LOG.md`, включно з датою наступного повторення через 7 днів для тем зі статусом «частково» або «повторити».
