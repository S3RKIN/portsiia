# Порція

Український калькулятор рецептів: вкажи кількість порцій і отримай зручні для кухні кількості інгредієнтів.

Статус: готове й протестоване ядро перерахунку. Вебінтерфейс у розробці.

## Запуск

Потрібен Node.js 22.18 або новіший.

```bash
npm test
```
